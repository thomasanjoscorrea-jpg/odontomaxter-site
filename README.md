# Site OdontoMaxter — modelo de demonstração

Proposta de site para a Clínica OdontoMaxter (Samambaia Norte, Brasília - DF).

- Página única, sem dependências: HTML, CSS e JavaScript puros
- Agendamento direto pelo WhatsApp, tratamentos com filtro, antes e depois interativo, depoimentos e mapa
- Marcado como `noindex` e com faixa de demonstração até a aprovação da clínica

Para ver localmente, abra o `index.html` no navegador.
